<summary><b>🟢 Phase 1: The Foundations of Logic (Days 1–10)</b></summary>
<br>
Focus: Core Python mechanics, control flow, data structures, functions, and module management.

- [x] **Day 1: Environment Setup & Basic Syntax** - Installing VS Code/Python, writing the first script, understanding variables, integers, floats, strings, booleans, and basic arithmetic operators.
- [ ] **Day 2: Control Flow & Logic** - Deep dive into `if`, `elif`, `else` statements, nested conditionals, comparison operators (`==`, `!=`, `<`, `>`), and logical operators (`and`, `or`, `not`).
- [ ] **Day 3: Looping Constructs** - Mastering `for` loops, `while` loops, the `range()` function, and loop control statements (`break`, `continue`, `pass`).
- [ ] **Day 4: String Manipulation & Formatting** - String slicing, indexing, f-strings, common string methods (`.upper()`, `.split()`, `.replace()`), and an introduction to Regular Expressions (Regex).
- [ ] **Day 5: Lists & Tuples** - Creating lists, indexing, slicing, appending, removing, understanding immutability with tuples, tuple unpacking, and basic list comprehensions.
- [ ] **Day 6: Dictionaries & Sets** - Key-value pair mapping, iterating through dictionaries (`.keys()`, `.values()`, `.items()`), set creation, and set theory operations (union, intersection, difference).
- [ ] **Day 7: Functions & Scope** - Defining functions (`def`), returning values, default parameters, understanding local vs. global scope, `*args`, `**kwargs`, and writing standard Docstrings.
- [ ] **Day 8: Functional Programming** - Anonymous functions using `lambda`, and utilizing functional mapping tools like `map()`, `filter()`, and `reduce()`.
- [ ] **Day 9: Modules & Virtual Environments** - Importing standard libraries (`math`, `random`, `datetime`), installing external packages with `pip`, and managing dependencies using virtual environments (`venv`) and `requirements.txt`.
- [ ] **Day 10: Exception Handling** - Anticipating and managing errors using `try`, `except`, `else`, `finally` blocks, and raising custom exceptions to prevent script crashes.
</details>
